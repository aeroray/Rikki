# Constraints

- Keep existing MemoryCustodian and design files (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `DESIGN.md`, `docs/memory/`). Do not delete them during scaffolding.
- v1 targets Windows and macOS desktop only.
- Use pnpm as the package manager.
- The launcher process stays resident while the window is hidden so the global hotkey keeps working. A tray icon is the visible handle to reopen or quit.
- Visual tokens follow `design/DESIGN.md` (cool near-black `#07080a`, lavender `#5e6ad2` as the only accent, 4px spacing grid).
- Source files are UTF-8 without BOM. Do not round-trip a file containing non-ASCII through PowerShell `Get-Content -Raw` / `Set-Content` without an explicit UTF-8 encoding: PowerShell 5.1 reads with the system ANSI code page, which silently corrupts characters such as the arrow glyphs used in key hints. Use the editor tools, or pass `-Encoding UTF8` on both sides.
- Persist todos in `app_data_dir/todos.json`, calc history in `calc-history.json`, clipboard history in `clipboard/index.json`, snippets in `snippets.json`, settings in `settings.json`, installed-app cache in `apps.json`, launch counts and command visits in `usage_count.json` (app paths and `command:{id}` keys), anniversaries in `anniversaries.json`, and extracted app icons in `apps/icons/`. A clip entry is `text`, `image` or `files`; `content` holds the body, which for `files` is the copied paths joined by a newline. Clipboard images live in `clipboard/images/`: text has no count cap but a single body over 512k characters is skipped, images cap at 200 files, and a single image over 5MB is skipped. Text retention is 7 or 30 days or never (`clipTextRetentionDays`); expired unpinned text is removed only by the settings cleanup action, and `files` entries expire with it. Do not use `localStorage` or other frontend stores.
- Releases ship exactly two packages, both unsigned: the NSIS installer for `x86_64-pc-windows-msvc` and the DMG for `aarch64-apple-darwin`. The installer is `perMachine` so the path is `C:\Program Files\Rikki` whatever the account is called, and it is multilingual with the product name left in English. The updater signing key lives outside the repository at `~/.tauri/rikki-updater.key`, with its password beside it; the public half is in `tauri.conf.json` and must never be replaced, because every installed copy verifies downloads against it.
- The Rust crate and the npm `@tauri-apps/*` packages have to stay on the same major/minor, or `tauri build` refuses to run ("Found version mismatched Tauri packages"). Adding a plugin can pull the crate forward, so bump `@tauri-apps/api` and `@tauri-apps/cli` in the same change. `webview2-com` in `src-tauri/Cargo.toml` is pinned to whatever `tauri` resolves, for the same class of reason.
