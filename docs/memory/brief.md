# Project Brief

Purpose:
- Rikki is a Windows and macOS Spotlight-style desktop launcher. A hotkey opens a small glass search palette; command prefixes trigger features. The mascot is a raccoon (Rikki ≈ raccoon, sounds like "quick").

Current direction:
- Root search launches installed apps (no `open` prefix), with icons, launch-frequency ranking, and `pinyin-pro` matching. The empty-home command list ranks by use count (`command:{id}` in `usage_count.json`), with clip and snippet first when counts are tied. `clip`, calc, todo, `sn`/`snippet`, `em`/`emoji`, `tr`/`translate`, `color`/`clr`, `json`/`jsonf`, `b64`/`b64d`, `ts`/`timestamp`, `qr`/`qrd`, and `settings` stay prefix commands. Hex, rgb, and hsl values also open the color panel from root search with no prefix. `gg`, `bd`, `bing`, `ddg`, and `sogou` open that engine in the browser. `tr`/`translate` needs no key and talks to Youdao alone: a sentence gets two translations, a fast one and an advanced one, both streamed, and a single word gets a dictionary card with US/UK phonetics and audio. A sentence can be read aloud as well. The source is detected from the script and `Tab` cycles the remembered target, which is one setting. Settings cover search engine (including custom `%s` URLs), theme (`system` / dark / light, `system` by default), the palette hotkey, language (`system` / 简体中文 / English), clipboard text retention (7 / 30 / never; cleanup is a settings action, not automatic), two rows that move the data itself — 导出配置 opens the system save dialog and writes a timestamped JSON file of todos, snippets and settings wherever the user points (a desktop, a sync folder), and 导入配置 opens the system open dialog, reads the file it returns, and asks through the usual confirmation before replacing those three (clip is not included) — and 检查更新, which asks GitHub Releases whether there is a newer version, verifies the download against a public key compiled into the app, and restarts into it. There is no backup folder, list or snapshot, and the update check is the only request the app makes on its own: one a few seconds after launch, then one per palette opening on a six-hour throttle, shown in a bar that sits under the power countdown and can be closed for that version. Unmatched queries of 2+ characters search the web with the default engine. `lock` and `sleep` run immediately; `shutdown`, `reboot`, and `logout` ask for a second Enter because they cannot be undone. A tray icon stays while the palette is hidden. The palette restores the last query after blur or hotkey hide. Escape from a command, color value, or search query clears it and returns to the empty home; Escape on home hides. Completed actions still reset. In-app spec is `design/DESIGN.md`. Dark canvas is `#07080a`; home rows use usage ranking and a translucent selected fill.

System shape:
- Tauri v2 (Rust) + SvelteKit 2 / Svelte 5 + Tailwind CSS 4, packaged with pnpm. Todos persist in `todos.json`, calc history in `calc-history.json`, clipboard history in `clipboard/index.json` plus `clipboard/images/` (no count cap on text but half a million characters per body, copied file lists as their own entry type, 200 images, 5MB per image), snippets in `snippets.json`, settings in `settings.json`.
