# Project Brief

Purpose:
- Rikki is a Windows and macOS Spotlight-style desktop launcher. A hotkey opens a small glass search palette; command prefixes trigger features. The mascot is a raccoon (Rikki ≈ raccoon, sounds like "quick").

Current direction:
- Root search launches installed apps (no `open` prefix), with icons, launch-frequency ranking, and `pinyin-pro` matching. The empty-home command list ranks by use count (`command:{id}` in `usage_count.json`), with clip and snippet first when counts are tied. `clip`, calc, todo, `sn`/`snippet`, `em`/`emoji`, `tr`/`translate`, `color`/`clr`, `json`/`jsonf`, `b64`/`b64d`, `ts`/`timestamp`, `qr`/`qrd`, and `settings` stay prefix commands. Hex, rgb, and hsl values also open the color panel from root search with no prefix. `gg`, `bd`, `bing`, `ddg`, and `sogou` open that engine in the browser. Settings cover search engine (including custom `%s` URLs), dark/light theme, the palette hotkey, language (`system` / 简体中文 / English), Baidu Translate (AppID/secret plus default and second target languages; credentials save as you type), clipboard text retention (7 / 30 / never; cleanup is a settings action, not automatic), and JSON backup import/export of todos, snippets, and settings (not clip). Unmatched queries of 2+ characters search the web with the default engine. `lock`, `sleep`, `shutdown`, `reboot`, and `logout` run immediately. A tray icon stays while the palette is hidden. The palette restores the last query after blur or hotkey hide. Escape from a command, color value, or search query clears it and returns to the empty home; Escape on home hides. Completed actions still reset. In-app spec is `design/DESIGN.md`; root `DESIGN.md` remains the Linear token reference.

System shape:
- Tauri v2 (Rust) + SvelteKit 2 / Svelte 5 + Tailwind CSS 4, packaged with pnpm. Todos persist in `todos.json`, calc history in `calc-history.json`, clipboard history in `clipboard/index.json` plus `clipboard/images/` (uncapped text, 200 images, 5MB per image), snippets in `snippets.json`, settings in `settings.json`.
